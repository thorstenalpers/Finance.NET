### What's Changed

* A Yahoo history request whose range contains no trading day (a weekend, or today for a fund whose NAV is not out yet) now fails immediately with `FinanceNetNoDataException` naming the symbol. Previously the page was read as a changed layout and retried through the whole back-off budget before failing. Thanks to @werwolfby for the report and the fix.
* The detection only accepts a table that collapsed to a single error cell, so a genuine layout change on Yahoo's side is still reported as a retryable `FinanceNetException`.
