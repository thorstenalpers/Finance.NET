### What's Changed

* New `FinanceNetAccessDeniedException` (derives from `FinanceNetException`) for a request Alpha Vantage refuses for the account: a premium-only endpoint called with a free key, or an invalid or missing API key. It is thrown by all four Alpha Vantage methods, is excluded from the retry policy and is not wrapped, so `InnerException` is null. Such a call now fails in well under a second instead of running through the whole back-off budget, which took several minutes. Thanks to @werwolfby for the report and the fix.
* An Alpha Vantage rate-limit notice stays a retryable `FinanceNetException`. `GetOverviewAsync` previously read the notice as an empty overview and reported `FinanceNetNoDataException` without retrying.
* `GetRecordsAsync` still calls `TIME_SERIES_DAILY_ADJUSTED`, which Alpha Vantage serves to premium keys only. With a free key it now fails immediately with `FinanceNetAccessDeniedException`.

### Behaviour Changes

* Existing `catch (FinanceNetException)` blocks keep working. Code that matches on the exact exception type or on the message of a refused Alpha Vantage request needs updating, because the type is now `FinanceNetAccessDeniedException` and the message changed.
